# 레퍼런스급 영상으로 개선하는 실행 계획

현재 검증 모델은 창작한 설명용 파빌리온이다. DDP의 실측 형상이나 내부 구조를 복원한 결과가 아니다. 에이전트의 제작·수정 경로가 작동하는 것과 레퍼런스급 시각 품질을 달성하는 것은 별도 판정이다.

## 다음 개선 작업의 순서

### 1. 고품질 자산 하나를 기준으로 고정

처음부터 모든 건물을 자동 모델링하려 하지 않는다. 먼저 특정 소재 하나에서 `hero/외피/내부/연결부`가 필요한 카메라 거리에서 버틸 수 있는 자산을 확보한다. 외부 모델은 파일 이름 대신 실제 실루엣과 부품 구조를 검사한다. 분리할 수 없는 합쳐진 메시라면 필요한 부분을 분리하거나 교체한다.

완료 증거: 참조와 같은 구도의 대표 프레임, 다른 두 각도, 가장 가까운 촬영 거리의 연결부. 원본 정체성·형상·분리 가능성·표면 품질을 각각 판정한다. 저해상도에서만 그럴듯한 자산은 통과시키지 않는다.

에이전트 경로: asset search/fetch → prepare 1차 → inventory/여러 각도 이미지 검토 → part/anchor mapping → prepare 2차 → import_prepared_asset.

### 2. 대표 화면 하나를 실제 비교로 완성

카메라 거리·렌즈·프레임 안 대상 크기를 먼저 맞춘다. 그 다음 큰 조명 방향, 밝고 어두운 영역, 금속 반사의 모양, 부품 두께 순으로 수정한다. 노이즈가 아닌 형상/조명의 차이를 샘플 수로 해결하려 하지 않는다.

한 번에 변수군 하나를 바꾸고 이전 버전을 유지한다. 렌더에는 동일 시점과 동일 해상도를 사용한다. 세 번 수정해도 같은 문제가 남으면 자산이나 촬영 구도를 바꾼다.

완료 증거: 원본/이전/수정 버전의 나란히 보기와 각 차이에 대한 판정. 가장 가까운 컷의 원본 픽셀 크기 확인. 애매하면 needs_work로 남긴다.

### 3. 패널 분리를 '공간 설명'으로 재설계

다음 파빌리온 수정은 먼저 카메라 앞쪽 패널 2–3개 묶음을 옆으로 열어 연결부를 드러낸다. 이어 주변 패널을 다른 높이·거리로 분리하되 핵심 부위를 가리지 않게 한다. 모든 판을 같은 거리로 올리는 동작에서 벗어난다. 필요하면 끝에 일부 재조립해 구조 관계를 다시 보여준다.

에이전트는 대상 part 목록과 rest pose를 유지하고 `peel/explode/assemble`을 조합한다. 판이 휘어지는 장면은 현재 강체 분리와 다르므로 별도 변형 리그가 필요하다고 명시한다.

완료 증거: 30fps 전체 프리뷰에서 관통·깜빡임·가림 없이 핵심 정보가 보임. 사용자가 “순서 반대”, “거리 절반”, “시작 1초 늦게”를 요청했을 때 해당 동작만 수정됨.

### 4. 전체 이야기를 먼저 편집

최종 렌더 전에 360p·30fps 전체 초안을 본다. 18초 예시라면 0–2초 외관/질문, 2–6초 외피 분리, 6–10초 내부, 10–14초 연결부, 14–18초 관계 정리 같은 구성을 시험할 수 있다. 이는 소재마다 바꿀 연출안이며 고정 템플릿이 아니다.

내레이션을 먼저 넣고 말이 끝나는 시점과 시각 사건이 맞는지 확인한다. 최종 음성의 실제 문자 타이밍이 생기면 timing resolve로 발화에 묶인 동작을 고정하고 바뀐 컷만 다시 렌더한다.

완료 증거: 해상도가 낮아도 무슨 이야기를 하는지 이해되고 빈 시간이 의도적인 전체 편집본. 최종 음성을 잘라서 억지로 맞추지 않음.

### 5. 고화질과 그래픽을 별도로 마무리

최종 1080×1920 대표 프레임 세 장을 먼저 측정하고 전체 출력 시간을 계산한다. 기기별로 EEVEE/Cycles/Metal을 실측해 선택한다. 이번 환경에서는 EEVEE와 Metal 접근 오류가 있어 CPU Cycles가 검증된 경로다. (정정 2026-10-04) Metal 오류는 Codex 샌드박스 한정이었다. 현재 기본은 Metal GPU Cycles(look 64spp, final 128spp)다.

라벨·자막·글꼴·안내선 위치는 3D 재렌더 없이 수정한다. 대상이 가려졌을 때 숨길지 점선으로 설명할지 명시한다. 후반에 작은 글자가 읽히는지는 축소된 실제 화면 크기로 확인한다. 최종 음성/음악/효과음 사용 권리를 갖춘 뒤 음량과 동작을 맞춘다.

완료 증거: 실제 최종 해상도 원본, 기술 QA, 전체 재생 검토와 사용자 시각 판정. 출력 규격이 맞는다는 이유로 참조 수준을 통과시키지 않음.

## 반복할수록 빨라지는 이유

완성된 장면은 `.blend` 버전으로 남는다. 좋은 자산은 라이브러리에서 다시 가져온다. 검증한 재질·카메라·동작은 코드와 스타일로 재사용한다. 새 요청에서 이미 해결한 요소를 다시 생성하지 않으므로 수정 대기시간이 줄어든다. 초기 자산 제작 시간과 같은 자산의 재촬영 시간을 별도로 기록한다.

새 소재 두 개 이상에서 이 절차가 통과한 뒤, 반복적으로 잘 되는 shot recipe를 묶는다. 그 시점에 한 명령으로 거의 완성품을 얻는 범위를 확장한다. 현재의 설명용 예제 한 편을 모든 소재의 품질 보장으로 확대하지 않는다.
