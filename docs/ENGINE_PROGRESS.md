# 엔진 진행 기록 — 레퍼런스급 건축 해부도 릴을 처음부터 만드는 엔진

이 문서는 2026-10-04~05에 걸쳐 엔진(studio CLI + Blender + Astra 스킬)을 어떻게 키워 왔는지, 지금 어디까지 왔는지,
무엇이 남았는지를 한곳에 모은다. 단계별 측정값과 명령은 `docs/BUILD_REPORT.md`, 에이전트 규칙은
`.agents/skills/reel-production/SKILL.md`와 `references/`에 있다. 레퍼런스 릴은 내부 측정용으로만 쓰며,
저장소에는 숫자와 sha256만 남긴다(프레임·경로·영상은 올리지 않는다).

## 목표

레퍼런스 릴을 베끼는 것이 아니다. 같은 문법(외관 → 단면 → 구조 → 디테일)의 영상을 **아무 주제로나 같은 품질 이상**으로 만드는 엔진이 목표다.

역할 분담 원칙:
- **Blender**: 구조, 위치, 개수, 카메라, 글자, 치수 — 틀리면 안 되는 것.
- **생성모델**: 질감, 화려함, 분위기 — 틀려도 되는 것.
- **사람**: 생성 전에 추가할 것을 말하고(HITL), 결과 테이크를 고른다.

1. s01 채움 계획 시트(`projects/.../samsung_moves/fill/s01/brief.md`)를 보고 더하거나 뺄 것 → `fill revise` → `fill approve`.

## 원칙(이 과정에서 굳어진 것)

- **원칙을 사례 나열로 바꾸지 않는다.** 예를 들어 하늘 확보는 "이 건물을 낮춰라"가 아니라 sightline 닫힌 식이다. 아직 없는 다음 경우를 하나 넣어 봐서(N+1 시험) 코드를 안 고쳐도 맞아야 원칙이다.
- **눈 대신 숫자로 판단한다.** look/motion/composition 스타일은 레퍼런스에서 학습한 사분위 범위로 판정한다.
- **실패는 빌드에서 막는다.** 예: `MOVE_PATH_LOOP`, `REVEAL inside-out`, `TITLE_OUT_OF_SAFE`, `GRAPHIC_ILLEGIBLE`, `graphic_in_frame`, `framing`.
- **승인은 사용자 말로만 받는다.** 유료 생성은 리뷰 시트 + 사용자 원문 + 요청 지문에 묶인 승인이 있어야 한다.
