# 아스트라에게 블렌더 자유를, 선은 지키게 — 계획 (2026-10-06)

사용자 판단: 생성 모델은 걱정 없고, 병목은 아스트라가 블렌더를 다루는 부분이다. 목표: 자유도를 크게 주되 선은 넘지 않게.
원칙(합의됨): **무엇을 시도할지는 자유롭게, 판단은 엄격하게.** 선은 프롬프트가 아니라 구조(프로세스 분리·기본 거부·측정)로 지킨다.

## 조사 결과 (에이전트 4개, 읽기 전용)
1. **실행 환경:** 아스트라는 codex exec(`gpt-6-astra`, workspace-write, 네트워크 꺼짐)로 돈다. codex CLI 0.160 설치됨.
   **아스트라는 워크벤치(MCP)를 한 번도 쓴 적이 없다** - 지난 실행은 전부 셸 명령. 결정 사다리 때문에 무인 실행은 첫 승인 시트에서 멈춘다.
   과거 실행 기록(`~/.codex/sessions/.../rollout-*.jsonl`, `one_command_validation/`)이 남아 있어 "어디서 막히는지" 측정 가능.
2. **자유 표면:** 데이터(장면·사양)와 워크벤치는 닫힌 어휘 + 검증이 있다. **저자 스크립트와 리그 스크립트는 무제한 파이썬이고, 빌드의 게이트와
   같은 인터프리터에서 돈다** → 게이트 함수를 바꿔치기, 작업 데이터(STUDIO_JOB) 변조, 파일 쓰기, 네트워크, 핸들러 등록, 외부 라이브러리 링크가
   가능하고 아무것도 못 잡는다. 키(FAL_KEY 등)가 블렌더 환경으로 넘어간다. 워크벤치 빈틈: 실패한 exec는 커밋 가능, `apply_shot` 직접 호출 가능,
   셸에서 `--allow-exec`는 프롬프트 규칙뿐.
3. **확장 지점:** 새 빌더·연동·무브를 추가하는 길은 엔진 코드뿐. 사양 생성기(조합)는 안전한 승격 경로(lint → 빌드 → fidelity → 라이브러리)가
   있지만 사용자 승인 단계가 없다. 동기화 테스트 빈틈: 빌더 목록↔스키마, 무브↔스키마, 셰이더·키트↔스키마, 연동 solve 누락, 빌더 params 오타 무시,
   연동 검사가 lint에서 안 돎.
4. **검사 목록:** 방법과 무관하게 도는 건 배관(카메라 존재·누락 파일·해시·승인)뿐. 화면 품질 검사는 기능을 선언했을 때만 돌고 픽셀을 거의 안 본다.
   **오늘 겪은 7가지(막힌 링, 근거리 잘림, 작업대가 화면 덮음, 핵심 부품 가림, 가장자리 걸림, 떠 보임, 모따기 없음) 중 확실히 잡히는 건 0.**
   계산된 무브는 조준 대상이 빈 오브젝트라 "대상 가림" 검사가 조용히 꺼진다. 룩의 `fail_on`은 gates.py 밖의 두 번째 완화 경로.

## 설계: 자유의 층과 선
| 층 | 자유 | 선 (구조로) |
|---|---|---|
| L0 데이터 (장면·사양·편집) | 완전 자유 | 이미 있음: 스키마·읽기 표·lint |
| L1 워크벤치 도구 | 자유 탐색, 변형 비교 | 커밋 재현 검사; exec 빈틈 막기 |
| L2 저자 스크립트 (자유 bpy) | **허용** - 데이터로 못 하는 모든 것 | **별도 프로세스**, 허용 목록 import, 환경 키 제거, 실행 후 장면 감사 |
| L3 contrib 어휘 (새 빌더·연동·무브·사양 생성기) | 아스트라가 직접 작성, **승격도 자동** | 순수 함수 + 매니페스트 + 자동 계약 테스트 → 프로젝트 빌드에서 사용·fidelity 통과 → **자동 승격**(버전 고정, 출처 기록, 폐기 가능) |
| L4 표현 설정 (색 보정·컴포지터·렌더 엔진 설정·Blender 내장 애드온·외부 에셋 링크) | **열림** - 데이터로 선언하거나 스크립트로 바꾸면 허용 | 막지 않고 **기록**: 선언(`shot.render.grade`, `compositor`, `engine_settings`, `addons`)은 룩 뒤 단계에서 적용되어 버전·렌더 지문에 들어감; 스크립트가 바꾼 설정은 감사가 차이를 기록(거부 아님); 링크된 에셋은 빌드 끝에 내장(local+pack)해 버전 불변 유지; 애드온은 Blender에 포함된 것만(외부 코드는 L3 경로로) |
| 품질 | - | **방법과 무관한 화면 측정** (생성 끝에서 실제 카메라로) |

## 단계
| # | 내용 | 규모 |
|---|---|---|
| P0 | **기준선 실측:** 새 기구 주제(사용자 선택)로 아스트라 1회 실행 - 결정은 요청에 미리 넣고, 워크벤치 프리뷰까지, 유료·무거운 렌더 금지. 이벤트 스트림 저장, 막힌 지점·반복·오류 집계(과거 rollout도 같은 지표로) | 0.5일 |
| P1 | **화면 측정(frame probe):** generate 끝에서 실제 카메라·클립면으로 Workbench id 패스 8~12프레임 → 빈 프레임·근거리 잘림(하드), 핵심 부품 가시율(하드, 설명 컷), 가장자리 잘림·피사체 비율·받침/배경 비율·피사체/배경 대비·접촉·모따기 가시성(완화 가능). 투영 검사들을 클립면 인식으로 고침, 조준 빈 오브젝트일 때 원래 대상을 지킴, revolve 막힘 lint, 룩 `fail_on`을 gates.py로 일원화 | 1~1.5일 |
| P2 | **저자 스크립트 격리:** 저자 단계를 별도 블렌더 프로세스로 분리(authored.blend만 넘김 → 게이트·작업 데이터 변조 불가, 핸들러 소멸), AST 허용 목록(bpy·mathutils·math·numpy·프로젝트 모듈; os·subprocess·소켓·파일 쓰기·exec·핸들러·sys.modules 금지), 블렌더 환경에서 키 제거, 실행 후 감사(렌더/색 설정, 링크 라이브러리, studio_id 보존, 3D 텍스트, 리그 샷의 카메라). 리그 스크립트도 같은 규칙. 경로 규칙을 프로젝트·examples로 좁힘 | 1~1.5일 |
| P3 | **값싼 빈틈:** 레지스트리↔스키마 동기화 테스트 5종, 연동 검사를 lint로, 빌더 params 읽기 표, 워크벤치(실패 exec 표시, `apply_shot` 숨김, 셸 `--allow-exec`에 사용자 원문 요구), 수정 금지 파일을 빌드 시작 때 해시 검사(승인 없으면 거부), 사다리 삭제 감지 | 0.5일 |
| P4b | **표현 설정 열기:** `shot.render.grade`(뷰 변환·룩·노출·감마·커브), `compositor`(노드 체인 선언: 글로우·렌즈 왜곡·비네트·그레인·색수차 등 허용 노드 종류 표 + 읽기 검사), `engine_settings`(Cycles/EEVEE 샘플·라이트 패스·노이즈 제거), `addons`(내장 애드온 이름) - generate의 룩 뒤 새 단계(수정 금지 파일 밖)에서 적용, 값 표는 읽기 표 방식으로 검사. 저자 스크립트가 바꾼 설정은 감사 보고에 차이로 남김. 링크 에셋 내장. 렌더 지문은 scene.blend 해시로 이미 따라감 | 1일 |
| P4 | **contrib 층:** `projects/<p>/contrib/`(초안) → `library/contrib/<kind>/<name>/vNNN`(승격). 종류: 빌더·단면·연동·무브(웨이포인트 생성)·사양 생성기. 로더(해시 확인, importlib, 이름 충돌 거부), 정적 게이트(bpy·os 금지, 순수 함수), 자동 계약 테스트(결정적·NaN 없음·닫힌 메시·방향·스케일 공변·읽기 표=매니페스트·프롬프트 단어·스키마 패턴 `contrib:name@vNNN`), 빌드 시 코드 해시 기록. **승격 자동**(사용자 결정 10-06): 계약 테스트 통과 + 프로젝트 빌드에서 사용 + 그 빌드의 fidelity·기구 간섭 통과 → `library/contrib/<kind>/<name>/vNNN` 자동 등록(코드·리포트 해시, 출처 프로젝트/샷/버전 기록). 쓰는 쪽은 버전을 고정하므로 이후 바뀐 버전이 기존 프로젝트로 번지지 않음; `contrib deprecate`로 새 사용만 막음. 로더·게이트·테스트는 수정 금지 그룹으로(아스트라가 검사를 약화 못 하게) | 2일 |
| P5 | **규칙·문서:** SKILL.md - 층별 자유와 선(저자 스크립트 허용 범위, contrib 절차, 화면 측정 코드), 참고 문서(`blender_freedom.md`, 블렌더 함정 모음), 기계 검사 표 | 0.5일 |
| P6 | **재실측:** P0과 같은 조건(다른 주제)으로 아스트라 재실행 → 막힘·반복·결과 화면 비교 | 0.5일 |
