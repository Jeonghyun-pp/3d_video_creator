# VIDEO PRODUCTION CHECKLIST

## A. Topic
- [ ] 대부분의 사람이 알고 있는 대상인가?
- [ ] 내부/작동 원리에 curiosity gap이 있는가?
- [ ] 단면/분해 시각화가 효과적인가?
- [ ] 30초 내 메시지 1개로 줄일 수 있는가?
- [ ] 향후 B2B 고객과 연결될 수 있는가?

## B. Research
- [ ] 공식/신뢰 가능한 자료가 있는가?
- [ ] 구조를 추측해서 그리는 부분이 없는가?
- [ ] 중요 치수/배치/순서를 확인했는가?
- [ ] 설명에서 불필요한 세부사항을 제거했는가?

## C. Script
- [ ] 첫 문장이 질문/사실로 즉시 진입하는가?
- [ ] 2초 안에 핵심 시각 요소가 등장하는가?
- [ ] 한 영상에 핵심 메시지가 하나인가?
- [ ] 문장마다 대응하는 화면이 있는가?
- [ ] 25~35초 안인가?

## D. Visual
- [ ] 첫 프레임 자체가 강한가?
- [ ] Exterior → Cutaway → Exploded → Mechanism 흐름이 자연스러운가?
- [ ] 강조 대상의 색이 명확한가?
- [ ] 자막 없이도 대략 이해 가능한가?
- [ ] 장면 사이에서 구조가 바뀌지 않는가?

## E. AI Video
- [ ] Text-to-Video보다 Image-to-Video를 우선했는가?
- [ ] motion prompt만 간결하게 입력했는가?
- [ ] no morphing / geometry consistency를 명시했는가?
- [ ] 생성 결과에서 새 구조물이 생기지 않았는가?

## F. Edit
- [ ] 대부분 컷이 2~4초인가?
- [ ] 자막은 1~2줄인가?
- [ ] narration과 화면 timing이 일치하는가?
- [ ] 첫 3초가 느리지 않은가?
- [ ] ending이 과도하게 길지 않은가?

## G. Publish
- [ ] Instagram Reels
- [ ] YouTube Shorts
- [ ] TikTok
- [ ] title/caption 기록
- [ ] 24h/7d metric 기록

## H. Performance Review
- [ ] 3초 유지율
- [ ] 평균 시청시간
- [ ] 완주율
- [ ] 공유
- [ ] 저장
- [ ] profile visit
- [ ] follows / profile visit
- [ ] 어떤 hook/subject/visual이 작동했는지 한 줄 기록
