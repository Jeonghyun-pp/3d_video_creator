# reel-production-v2 reference — module index
**Do not read all modules.** Read this index, then load only the modules of the phase you are in.

| Module | File | Read when... |
|---|---|---|
| Cuts plan | `cuts_plan.md` | writing or changing the cuts layer (Phase 1), answering a flow finding in the plan |
| Pictures | `pictures.md` | making, checking, picking and locating a cut's pictures (Phase 2) |
| Readers | `readers.md` | the preview's readers, the style and same-view readers, a reader asked outside the sandbox (Phase 3) |
| Paid video | `paid_video.md` | the video prompt's rules (Phase 1, a cut that moves); after the user's words on the sheet (Phases 4-5) |
| Rationale | `rationale.md` | a rule seems wrong for this reel; you want the measurement behind it |

## Phase → module loading
### Phase 1: cuts plan
1. **Always read**: `cuts_plan.md`
2. **Read if** a cut moves (a change, or a camera that is not still): the prompt section of `paid_video.md` - the cuts lint
   refuses a cut whose paid prompt breaks it
3. **Read if** a rule seems wrong here: `rationale.md`
### Phase 2: pictures
1. **Always read**: `pictures.md`
### Phase 3: preview and readers
1. **Always read**: `readers.md`
2. **Skim**: `cuts_plan.md` (the fix of a finding is in the plan)
### Phases 4-5: sheet and paid video
1. **Always read**: `paid_video.md`
